# 🌌 Explore Beyond Earth

An immersive, highly interactive 3D web experience designed to take users on a cinematic journey through our solar system and beyond. Built with modern web technologies, this project features stunning 3D planetary models, smooth animations, and an engaging user interface.

## ✨ Features

- **Interactive 3D Earth:** A highly detailed, rotating 3D model of Earth with Day/Night toggles and pause controls.
- **Cinematic Welcome Screen:** A breathtaking fullscreen entry sequence that pulls you into the cosmos.
- **3D Solar System Explorer:** An interactive orbital map where users can click on glowing planets to learn detailed fun facts, distances, and atmospheric data.
- **Responsive & Modern UI:** Glassmorphism design, floating animations, and a seamless dark mode aesthetic powered by Tailwind CSS and Framer Motion.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **3D Rendering:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/getting-started/introduction) (@react-three/drei)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
